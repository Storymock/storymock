# company()

Company-related data.

| Method | Returns | Description |
|---|---|---|
| `.name()` | `TextFaker` | Company name |
| `.catchPhrase()` | `TextFaker` | Catch phrase |
| `.buzzPhrase()` | `TextFaker` | Buzz phrase |

```typescript
company().name().create()    // 'Acme Corp'
```
